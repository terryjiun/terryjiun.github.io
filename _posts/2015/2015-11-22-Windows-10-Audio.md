筆者有一台桌上型電腦於 2010 年購入，使用華碩的主機板，音效卡內建於主機板上。<br>
對於大廠的主機板，微軟在新版的 Windows  都會將其驅動程式內建於作業系統，<br>
所以，不管是在這種 2010 年就出廠的主機板上安裝 2012/08/15 推出的 Windows 8，<br>
或是安裝 2015/07/29 推出的 Windows 10（或 2015/11/12 推出的 Win10 v1511），<br>
Windows 都會自動安裝好這塊主機板內建的網路卡、音效卡驅動程式，<br>
手動開啟「裝置管理員」檢查後，一切也都很正常。<br>
<br>
但是，筆者在 2015 年 8 月初安裝正式版的 Windows 10 就遇過驅動程式正常，<br>
喇叭的音源線插頭也插入到主機板上正確的音效卡插孔，但是卻播不出音樂的情況。<br>
當時，筆者曾經去拔喇叭插頭，換不同的插孔試驗，也曾想過手動更換驅動程式，<br>
後來，開啟「控制台」中的「聲音」，更改預設的播放裝置後，<br>
「無聲」的問題很順利的就迎刃而解了！<br>
<br>
而當筆者最近以 Clean Install 的方式重新安裝 Windows 10 Version 1511 後，<br>
遇到了同樣「沒有聲音」的問題，筆者居然笨到又去拔喇叭插頭，換不同的插孔試驗。<br>
筆者果然已經出現「初老」的症狀了！<br>
三個月前費了一番功夫才得到解決的事情，居然這麼快、這麼容易就忘得一乾二淨！<br>
因此，筆者決定把解決的方式在部落格上作成筆記，提醒自己，也分享給大家。<br>
<br>
如果您已經確定驅動程式沒有問題（可以開啟「裝置管理員」檢查有無驚嘆號的圖案），<br>
插孔也沒插錯（使用舊版 Windows 時，就是用原本的插孔），<br>
那麼就試試下列方式：<br>
<br>
1.開啟「控制台」，右上方的「檢視方式」選【小圖示】，再開啟「聲音」選項。

![控制台](/assets/img/windows/Windows-10-Audio-1.png)

2.開啟「聲音」選項時，系統可能會詢問以下問題，直接按【是】即可。

![Sound-1](/assets/img/windows/Windows-10-Audio-2.png)

3.出現下圖畫面時，預設裝置應該是「Headphone」（耳機），<br>
　　請點選「喇叭」，再按【設為預設值】，最後再按【確定】。

![Sound-2](/assets/img/windows/Windows-10-Audio-3.png)

設定完成後，可以開啟一段影片或音樂試試，此時應該可以順利播出聲音了！<br>
