本篇文章僅針對小小輸入法支援 Windows 8-style UI APPs 這件事情加以介紹、解說，<br>
如果各位看倌迫不及待要安裝「泰瑞版小小輸入法」，則請點選「★這篇文章」。<br>
<hr>
小小輸入法的作者（dgod，周永先生）<br>
最近替小小輸入法的「安裝（內置）版本」引進了新的內置技術，<br>
原本 Windows 版本的內置技術是使用 IMM（Input Method Manager），<br>
現在多了 TSF（Text Service Framework）可以選擇。<br>
採用 TSF 技術讓小小輸入法成為 Windows 內置的輸入法後，<br>
終於實現了「在 Windows 8 Metro 應用程式裡可以使用小小輸入法打字」這項創舉，<br>
從此，在 Metro 下的應用程式（IE、連絡人、天氣、Skype…）裡輸入漢字，<br>
不必再受限於只能使用微軟內建的輸入法，<br>
也不必再尋找或等待第三方推出支援 Metro 環境的輸入法了。<br>
<br>
目前，Windows 8 雖然有內建大易、行列輸入法，<br>
但是它們只能在桌面 AP 裡使用，不能在 Metro APP 裡使用；<br>
至於嘸蝦米，因為當初劉重次先生並沒有授權給微軟，<br>
因此，Windows 8 一如往常，並沒有內建無蝦米輸入法。<br>
本來，Windows 8 繁體中文版使用者，<br>
只能在 Metro APP 裡用內建的新注音、倉頡或是第三方（如：搜狗）推出的輸入法來輸入中文，<br>
現在因為小小輸入法更上層樓後，<br>
在 Metro APP 裡，用倉頡、大易、行列、嘸蝦米…輸入中文，<br>
再也不必靠微軟、行易或別家公司了。<br>
因為小小輸入法是個輸入法框架軟體，<br>
只要有輸入法對照表（碼表），任何輸入法都可以用它來實現。<br>
<br>
小小輸入法的 TSF 安裝方式，可以參考★這一篇文章，<br>
倉頡、大易、行列、嘸蝦米的使用者，<br>
如果有需要的話，建議下載「泰瑞版小小輸入法」回去使用，<br>
可以省去自行摸索的麻煩，<br>
而且在我的部落格的「★泰瑞版小小輸入法」分類裡，<br>
還有很多篇文章可以供您參考，讓您明瞭小小輸入法的使用、設定方式。<br>
當您成功將「泰瑞版小小輸入法」安裝到 Windows 8 後，<br>
到「控制台」→「語言」（或「新增語言」）項下，<br>
點選「選項」→「新增輸入法」，將會出現下列畫面：<br>
![泰瑞版小小輸入法](/assets/img/terry_yong/Windows-IME-Terry-Yong.png)
圖中，顯示「只適用於桌面」的輸入法，無法在 Metro APP 環境下使用，<br>
沒有顯示「只適用於桌面」的輸入法，正常情況下是可以在 Metro APP 環境下使用的。<br>
值得注意的是：<br>
Metro APP 環境下，並不會顯示輸入法的主窗口（語言列），<br>
即便是微軟內建的新注音、倉頡亦然，小小輸入法更是如此，<br>
所以是否已經切換到全型、繁轉簡、想要的輸入法模式或種類…<br>
就只能打幾個字試試了！<br>
而這也是很多人不喜歡 Metro UI 的原因，<br>
總覺得少了視窗的縮小、放大（或還原）、關閉按鈕很彆扭，<br>
現在少了輸入法主窗口更是難過。<br>
不過，對於觸控螢幕、尺寸較小的螢幕而言，<br>
這或許是現今微軟覺得比較好的 UI（User Interface，使用者介面）。<br>
雖然，小小輸入法目前在 Windows RT、Windows Phone 8 上，可能還無法使用，<br>
但是，能有今日的成果，顯示它已經跨出一大步了！<br>
