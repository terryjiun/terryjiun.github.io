以下就「顯示」與「輸入」兩個面向，<br>
對 Windows 作業系統的新細明體支援（收錄、收納）的字元做一下整理。<br>
<br>
## Windows 95/98/ME
內建的輸入法最多只能輸入 13,060 個 Big5 碼的字元<br>
（實際上這些字元並沒有全部都被輸入法支援），<br>
如果使用 Word 這類可以支援 Unicode 字元的軟體<br>
（註：Word 97 及其以後的版本支援 Unicode），<br>
要顯示 Unicode CJK 的 20,902 個字元還是有問題的！<br>
因為新細明體版本太舊了！<br>
（可以安裝 Office 2000，安裝時需使用完整安裝，但不能保證可以更新成功）<br>
<br>
## Windows NT 4.0 Workstation/Server
內建的輸入法最多只能輸入 20,902 個 Unicode CJK 的字元<br>
（實際上這些字元並沒有全部都被輸入法支援），<br>
預設情況下可以直接打出「煊」、「堃」這些字，<br>
如果希望只出 Big5 碼的字，很抱歉！並不能在輸入法設定裡調整。<br>
如果使用 Word 這類可以支援 Unicode 字元的軟體<br>
（註：Word 97 及其以後版本支援 Unicode），<br>
要顯示 Unicode CJK 的 20,902 個字元還是有問題的！<br>
因為新細明體版本太舊了！<br>
（可以安裝 Office 2000，安裝時需使用完整安裝，但不能保證可以更新成功）<br>
註：它的新細明體版本和 Windows 95 的是一樣的！<br>
　　但奇怪的是：NT 的檔名可以用「煊」、「堃」這些字。<br>
<br>
## Windows 2000/XP/Server 2003
內建的輸入法最多只能輸入 20,902 個 Unicode CJK 的字元<br>
（實際上這些字元並沒有全部都被輸入法支援），<br>
預設情況下可以直接打出「煊」、「堃」這些字，<br>
如果希望只出 Big5 碼的字，也可以在輸入法設定裡調整。<br>
如果使用 Word 這類可以支援 Unicode 字元的軟體<br>
（註：Word 97 及其以後版本支援 Unicode），<br>
那麼顯示 Unicode CJK 的 20,902 個字元是沒有問題的。<br>
（表示它們的新細明體字型已經收錄了那 20,902 個字，<br>
而且它們的輸入法也支援那 20,902 個字）。<br>
<br>
以上所提的各版本的 Windows，在「預設情況下」，<br>
都不能輸入及顯示中日韓統一表意文字（CJK Unified Ideographs）擴展 A、B 區的字元，<br>
除非透過前述三篇講述的方式或其他方式來達成。<br>
<br>
## Windows Vista/Server 2008
內建的輸入法「預設」情況下可以輸入 20,902 個 Unicode CJK 的字元，<br>
而且不需加裝其他軟體，只要透過調整輸入法的設定，<br>
即可輸入擴展 A、B 區的字元，<br>
（預設情況下可以直接打出「煊」、「堃」這些字，<br>
如果希望只出 Big5 碼的字，也可以在輸入法設定裡調整，<br>
但實際上這些字元並沒有全部都被輸入法支援）。<br>
如果使用 Word 這類可以支援 Unicode 的軟體，<br>
（註：Word 97 及其以後版本支援 Unicode），<br>
那麼不需加裝任何字型即可顯示中日韓統一表意文字的 70,195 個字元<br>
（最初期統一的 20,902 個字元、擴展 A 區的 6,582 個字元、擴展 B 區的 42,711 個字元）。<br>
<br>
## 感想
「新細明體更新套件」安裝檔的「數位簽章」日期是2005年4月20日，<br>
表示它已經發佈 3 年半了！<br>
但是相信很多人都不知道有這個套件<br>
（可能有很多人也還不知道在 Windows Vista/Server 2008 裡，<br>
透過輸入法設定的調整，就能比 Windows XP 多打出近五萬個漢字）。<br>
<br>
有需要用到「外字」（Big5 或 Unicode CJK 以外的字）的人，<br>
如果你要用的字已經在擴充 A 區及擴充 B 區裡，<br>
建議不要再使用麻煩的造字程式，或其他的字集補完計畫，<br>
好好的研讀我寫的這幾篇文章，<br>
希望看完後能對你有所助益！<br>
如果你使用的應用程式不支援（即不能顯示或儲存） Unicode 碼的話，<br>
最好向應用程式提供廠商反映一下！<br>
（現在新開發的網頁都用 UTF-8 編碼，資料庫也以 UTF-8 編碼儲存了，<br>
應用程式還死守 Big5 碼的話，就太過落伍了！）<br>
