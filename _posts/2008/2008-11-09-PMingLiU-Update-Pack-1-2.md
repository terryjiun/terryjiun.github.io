安裝方式：<br>
先將正在執行中的應用程式（Word、Excel…）關閉，<br>
然後下載「PMingLiU Update Pack.MSI」（新細明體更新套件），<br>
下載網址為（任選其一即可）：<br>
[下載網址1](https://www.tbmc.com.tw/computerese/pdf/PMingLiU%20Update%20Pack.msi){:target="_blank"}<br>
[下載網址2](https://www.hytung.cn/Charset/PMingLiU%20Update%20Pack.msi){:target="_blank"}<br>
儲存至磁碟機後直接開啟執行，<br>
基本上並沒有特別要注意的選項，<br>
一路按「下一步」直到完成安裝，<br>
最後詢問是否要立即重新開機時，選「是」，<br>
重新開機後就完成新細明體更新了！<br>

此 Readme 檔, readme.rtf，亦安裝在應用程式目錄 (預設是 \Program Files\MingLiu Font Update 目錄)。在開始使用此字型更新版本之前，請詳細閱讀以下的版本資訊。<br>
<br>
## 一、支援的系統
　　本更新程式僅支援在 Windows XP 中文版和 Windows Server 2003 中文版下安裝及執行。<br>
## 二、如何安裝
　　成功下載 ”PMingLiU Update Pack.MSI”安裝套件後，直接點選執行安裝，安裝程式會自動將字型檔案安裝至您的系統目錄，安裝完畢後重新開機即可。<br>
## 三、新增和修改檔案
　　本更新程式會將原本在 \Windows\Fonts 目錄下的『細明體 & 新細明體』﹝檔名：MingLiU.ttc 3.21版﹞更新為 5.03 版。 另外，會在相同的目錄下新增一個新的細明體字型檔，名稱是『細明體-ExtB & 新細明體-ExtB』﹝檔名：MingLiUＢ.ttc﹞，版本為 1.05 版。<br>
## 四、新舊字型檔所支援的字數比較
　　4-1. 舊版『細明體 & 新細明體』﹝MingLiU.ttc 3.21版﹞支援 Unicode 2.0，而 Unicode 2.0 已經包含了 Big5 碼，共提供了 20,902 個繁、簡中文和日、韓的漢字。<br>
<br>
　　4-2. 新版 『細明體 & 新細明體』 ﹝MingLiU.ttc 5.03 版﹞ 除了支援 Unicode 2.0 外，並增加了 Extension A 內的 6,582 個繁、簡中文和日、韓的漢字。換句話說，新版的字型檔已經支援到 Unicode 3.0，所支援的字數已高達 27,484個漢字。<br>
<br>
　　4-3. 新增的『細明體-ExtB & 新細明體-ExtB』﹝檔名：MingLiUＢ.ttc 1.05 版﹞內含有 Extension B 的 42,711 個繁、簡中文和日、韓的漢字。Extension B 就是 Unicode 中所定義的 Surrogate 區域，Surrogat 內的字是從 Unicode 3.1 版本中才有定義的。<br>
<br>
　　4-4. 如果安裝本更新檔案，您的系統便可升級到支援 Unicode 3.1 版，同時可使用到多達 70,195 個繁、簡中文和日、韓的漢字。<br>
## 五、輸入法
　　本更新程式亦會更新傳統注音輸入法和傳統倉頡輸入法，將原始只能輸入 Unicode 2.0 內的中文字或其他漢字，擴充到支援輸入 Extension A的中文字或其他漢字。至於您如欲輸入 Extension B 內的中文字或其他的漢時，可以使用新版的微軟新注音、倉頡輸入法 6.0 版的單碼功能輸入。有關最新的微軟輸入法 ， 請您到 台灣微軟的網站 下載區 下載最新的 Microsoft New IME 6.0 ﹝微軟新注音輸入法、微軟新倉頡輸入法、微軟輸入整合器﹞，網址如下：<br>
　　https://www.microsoft.com/taiwan/download/CHTdownload.htm。

<br>
微軟將這兩套新的字型做成「新細明體更新套件」這種〝安裝程式〞，<br>
是為了方便那些不知道怎樣安裝字型的人使用（當然安裝程式還有其他的功用，底下會提到），<br>
畢竟新細明體一直都是 WinXP 的「系統預設字型」，<br>
要更新「系統預設字型」並不像安裝一般的字型那麼容易，<br>
因為更新時會被 Windows 作業系統鎖定。<br>
但說實在的，<br>
更新「系統預設字型」的方式在看完下一篇的「新細明體更新套件（二）：解除安裝篇」後，<br>
聰明的你應該就會舉一反三了！<br>
你應該會想：<br>
<span style="color: purple">既然 Vista 的字型比「新細明體更新套件」的字型還新，<br>
那我們何不複製到 XP 上使用？</span><br>
<span style="color: blue">是的！這一點是沒有問題的，但需要一點技巧，而且有一些限制！</span><br>
Vista 的中文字型已經有網友提供出來了！<br>
他是在桌面上開一個新的資料夾，取名為「Vista&#95;Fonts」，<br>
然後進 Vista 控制台的「字型」裡，將 11 套中文字型拉到「Vista&#95;Fonts」資料夾內<br>
（在 Vista 下，這種拖曳的動作會等同「複製檔案」），<br>
然後做成壓縮檔；解壓縮後，到 XP 控制台的「字型」裡，在「標楷體」上按右鍵，選「刪除」，<br>
再將「新細明體」拉到桌面上，<br>
（在 XP 下，這種拖曳的動作會等同「移動檔案」，<br>
不做這個動作的話，<br>
等會兒新安裝的「mingliu.ttc」會被改名，<br>
而原來「C:\WINDOWS\Fonts」的「mingliu.ttc」會被保留，<br>
以致無法達到置換「系統預設字型」的目的）<br>
最後依安裝一般字型的方式，指定安裝來源為解壓縮後的「Vista&#95;Fonts」資料夾，<br>
安裝後再重新開機，就可以使用新的「系統預設字型」了！<br>
（被拉到桌面上的舊版「mingliu.ttc」可以刪除或移到別的地方）<br>
不過這裡要注意的地方是：<br>
這 11 套 Vista 中文字型中，<br>
只有 2 套「新細明體」的字型有支援 CJK、CJK Ext-A、CJK Ext-B，<br>
其他 9 套字型只有支援 CJK（最多再加上 CJK Ext-A）。<br>
<br>
另外，<span style="color: red">不要直接用上述的方法安裝「Vista 新細明體字型」而不先安裝「新細明體更新套件」！<br>
（此處所指「Vista 新細明體字型」包含「mingliu.ttc」、「mingliuB.ttc」兩套字型）</span><br>
因為不安裝「新細明體更新套件」而直接安裝「Vista 新細明體字型」的話，<br>
會發生下列問題：<br>
1.開啟本篇文章上集提到的「展示擴展 B 區字元」的網頁，會出現漢字變成空白。<br>
2.用「通用輸入法編輯工具」產生的「泰瑞倉頡輸入法」（後續文章會提到此輸入法），<br>
　在候選字窗格中，無法顯示擴展 B 區的字元。<br>
儘管把「新細明體更新套件」在系統組態登錄中增加的「mingliuB.ttc」資料（或機碼、值）複製過來，<br>
同樣會有一些問題，<br>
所以記得：<br>
<span style="color: red">安裝「Vista 新細明體字型」前一定要先安裝「新細明體更新套件」。<br>
安裝「Vista 新細明體字型」時，只是置換「mingliu.ttc」、「mingliuB.ttc」兩個字型檔，<br>
請勿解除安裝「新細明體更新套件」！</span><br>
