---
title: 叫出「Windows 工作管理員」的方式
date: 2008-05-31 10:10:00 +0800
categories: [作業系統]
tags: [Windows, 工作管理員]
---

很多人都知道在 Windows 作業系統中，<br>
可以利用 Ctrl + Alt + Del 叫出「Windows 工作管理員」。<br>
但是在 Windows Server 2003、Windows Vista、Windows Server 2008 環境下，<br>
按 Ctrl + Alt + Del 之後，其實會先出現一個選單<br>
（有「變更密碼」、「鎖定電腦」、「工作管理員」等項），<br>
而不是直接開啟「工作管理員」。<br>
<br>
要如何〝直接〞開啟「工作管理員」，而不必再點選項呢？<br>
答案是：<br>
用 Ctrl + Shift + ESC！<br>
（鍵盤左邊最下面的兩個鍵及最上面的一個鍵）<br>
<br>
這個方式在 Windows XP 應該也行得通喔！<br>
所以想直接呼叫「工作管理員」的人，習慣要改囉！<br>
