2015/7/14 補充說明：<br>
<br>
安裝 Windows 8/8.1/10 後，想要進入安全模式（F8）或以光碟、隨身碟開機的話，<br>
最快的方式就是找到「重新啟動」（重新開機）的選項時，<span style="color: red">先按住 Shift 鍵不放，再點選「重新啟動」</span>，<br>
然後放開 Shift 鍵及滑鼠左鍵，稍待片刻就會出現關機選項的畫面，再點選「繼續」就可以了！<br>
這是讓系統在下一次重新開機時暫時取消「快速啟動」功能，以便 User 操作一些 BIOS 功能鍵的最便捷方式。<br>
重新開機，在載入 BIOS 設定的過程，User 可以按 ESC（華碩筆電）或 F8（華碩桌機）呼叫 Boot Device Menu，<br>
這時就不會受到「快速啟動」功能的影響而讓這些 BIOS 功能鍵失效了！

2012/10/14 原文：<br>
<br>
Windows 8 改良了開機模式，讓開機速度飛快，<br>
可是，這可苦了想要進入安全模式，或是想要以光碟、隨身碟、外接式硬碟開機的使用者。<br>
<br>
一般的桌上型電腦或筆記型電腦開機時要經歷兩個階段：<br>
第1階段：啟動電源→POST→載入BIOS設定→載入開機程式→搜尋啟動的磁碟→啟動磁碟開機程式。<br>
可能是因為我的桌上型電腦裝了3顆硬碟的緣故，所以這個階段耗時約15秒，<br>
其實，不管我的電腦安裝什麼作業系統，這個階段所耗費的時間都是固定的。<br>
第2階段：啟動OS→自動登入（已先行設定登入 Win8 時，不需輸入密碼）→出現動態磚。<br>
這個階段有時花不到10秒鐘，真的快很多！<br>
但是，有時又沒這麼快，通常是關閉電源後，隔一段時間再開，才有這種速度。<br>
<br>
我的桌上型電腦和筆記型電腦都是用 ASUS（華碩）的主機板，<br>
我將 BIOS 都設成開機裝置的第1順位是第1顆硬碟，<br>
因為華碩的主機板在上述開機的第1階段時，可以按下「開機選單鍵」，<br>
呼叫出開機選單，選擇要從什麼裝置開機，<br>
所以，我這樣設定 BIOS 之後，仍然可以隨時切換開機裝置。<br>
華碩設定桌上型電腦的開機選單鍵是 F8，筆記型電腦的則是 ESC，<br>
但是裝了 Windows 8 之後，按下開機選單鍵後，卻破功了！<br>
開機選單根本就沒有出現，很快的就進入 Windows 8 的啟動畫面。<br>
後來，終於找到了答案，原來下一次重開機後，<br>
<span style="color: blue">如果想要進入安全模式，或是想要以光碟、隨身碟、外接式硬碟開機，<br>
（或是想要按下開機選單鍵時，不會失效）<br>
關機時就應該這樣做：<br>
將鼠標移動到畫面的右上角或右下角，呼叫出 Charms</span>（快速鍵，[這是微軟自己翻譯的](https://msdn.microsoft.com/zh-tw/library/windows/apps/hh465304.aspx){:target="_blank"}），<br>
<span style="color: blue">點選「設定」</span>（设置）<span style="color: blue">，出現下圖畫面：</span><br>
<br>
![Windows 8 Charm](/assets/img/windows/Windows-8-Start.png)<br>
<br>
<br>
<span style="color: blue">然後再依序點選：<br>
變更電腦設定→一般→立即重新啟動（這個按鈕在「一般」頁面裡的最底部）→繼續。<br>
（Windows 8.1 正體中文預覽版路徑改為：<br>
設定→變更電腦設定→更新與復原→復原→立即重新啟動→繼續）</span><br>
<span style="color: purple">簡體中文版則是：<br>
更改电脑设置→常规→立即重启（这个按钮在「常规」页面里的最底部）→继续。<br>
（Windows 8.1 簡體中文預覽版路徑改為：<br>
设置→更改电脑设置→更新和恢复→恢复→立即重启→继续）</span><br>
<br>
網路上訛傳的方式是「關閉 Windows 8 的快速啟動功能」，設定方式是：<br>
開啟控制台→（硬體和音效）→電源選項→選擇按下電源按鈕時的行為（畫面左上方選項）<br>
→變更目前無法使用的設定→取消勾選「開啟快速啟動（建議選項）」→儲存變更。<br>
因為我們並不是每一次開機都要進入安全模式或從光碟、隨身碟、外接式硬碟開機，<br>
所以這樣的設定方式只會造成 Windows 8 開機速度永遠都快不了！<br>
因此正確方式應該是上面說的第1種方法。<br>
