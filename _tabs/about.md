我是痞客邦《[泰瑞的世界](https://terryhung.pixnet.net/blog){:target="_blank"}》的站長，在此向大家問候！<br>
我的暱稱是「泰瑞」，英文名字是「Terry」，我姓「洪」（對應的拼音是 Hung、Hong 或 Horng）。<br>
我是一個資訊科技喜好者，在這個網站空間（虛擬世界）會記錄：<br>
我的心情點滴、生活瑣事、研究心得、經驗分享、知識收藏、實驗筆記……<br>
我希望我的文章對讀者們有幫助，但是我不對讀者讀後的任何行為、作用、影響、後果負任何責任。<br>
我在各篇文章裡會自稱「筆者」，以「讀者」稱呼閱讀此部落格的你／妳。<br>
<br>
這是一個用 GitHub Pages + Jekyll + Chirpy Theme 搭建而成的 Blog 空間，<br>
雖然可以套用留言板，但是誠如【[寫信聯絡泰瑞／回報無效連結](https://terryjiun.github.io/posts/E-Mail-to-Terry/){:target="_blank"}】一文所述，<br>
我不喜歡用留言板的方式與讀者們溝通、討論，所以我沒有設置留言板。<br>
各位如果有問題想聯絡我的話，敬請來信：terryhorng@hotmail.com<br>
<br>
我之所以會成立個人部落格是因為我有些發現、發明、心得，不想藏私，就會在這個空間上發表、分享，<br>
我不會去別的論壇宣傳我的文章、作品，也不想尋求同好，更不想成立任何組織，<br>
我只要試過用 Google、Bing、Yahoo 搜尋得到我的文章就好，至於點閱數、下載數、使用率……等，我並不在意。<br>
我也沒有想過要靠分享作品、寫作文章、製作教學來賺錢，所以超出我的部落格文章的題材就不用來信討論了！<br>
正所謂「聞道有先後，術業有專攻」，因此每個人研究、擅長的領域會有所不同，<br>
舉個例子來說，就算同樣是「輸入法」的領域，有些人偏好編碼的設計與邏輯，有些人則偏好軟體的使用與便利，<br>
彼此層次不同就道不同不相為謀，不用勉強聚在一起討論。<br>
能用搜尋引擎、AI產品找到解答、解決問題最好，不能的話就算了！<br>
所以我在網路上從不去向別人討教，也不指望別人能為我做什麼，我算是在網路這個江湖上自成一派的人吧！<br>
因此如果是層次不同、立場互斥、理念相左、廣告推銷、意識型態洗腦… 等信件，我收到後會視而不見喔！<br>
