前言：<br>
<br>
筆者發布【泰瑞版小小輸入法】已經超過 7 年的時間，<br>
以往每一次更新版本時，筆者只是重新包裝壓縮檔，對於異動部分甚少提及，<br>
原因無他，因為大多數的更新版本，筆者只是替換「核心程式」，因此能著墨的地方不多。<br>
不過，今後筆者想改變一下作法，將更新版本的歷程記錄於此篇文章。<br>
<br>
「核心程式」的更新歷程，筆者不會記錄於此，請讀者連結至【[小小輸入法─測試版本](https://yong.dgod.net/read.php?tid=2&fid=2){:target="_blank"}】一文查看，<br>
舉例說明：假設筆者前一次更新版本日期是 2017.04.13，此次更新版本日期是 2017.08.27，<br>
那麼連結至該網頁查看 2017.04.13～2017.08.27 期間的更新歷程，<br>
就可以知道周永先生在這段時間為小小輸入法平台增添了什麼功能、修正了什麼 Bugs。<br>
<br>
另外，目前【泰瑞版小小輸入法】支援 3 種平台：<br>
Windows 版有 3 個檔案：Terry&#95;Yong.zip、Terry&#95;Yong&#95;ExtE.zip、Terry&#95;Yong&#95;Lite.zip<br>
Linux 版有 1 個檔案：Terry&#95;Yong&#95;Linux.zip<br>
Android 版有 2 個檔案：Terry&#95;Yong&#95;Android.zip、Terry&#95;Yong&#95;Android&#95;CJKey.zip<br>
每次更新版本時，筆者會維持檔名不變，以利讀者識別。<br>
<br>
【泰瑞版小小輸入法】更新歷程：<br>
<br>
## 2017.08.27
只更新 Windows 版，變更項目如下：<br>
1. 「核心程式」更新至 2017.08.23 版本。<br>
2. 螢幕小鍵盤（軟鍵盤）的「數學符號」重新編排，添加一些符號。<br>
3. 組態檔案（yong.ini）中加入「併擊」功能的設置，但僅限於「泰瑞倉頡」。<br>
4. 倉頡碼表（Chajei.txt）「key=」加入「+」（併擊用），最末尾加上「使用者自訂併擊組字」段落。<br>
　 其他輸入法使用者如果想體驗「併擊」功能，可以參考上述 3、4 修改組態及碼表。<br>
<br>
## 2017.12.22
只更新 Windows 版，變更項目如下：<br>
1. 「核心程式」更新至 2017.09.07 版本。<br>
2. 修改 yong.ini：加入前 3 列的註解，以及「lang=0」的註解及設定值（預設仍為中打，有需要預設為英打者，請自行修改）。<br>
<br>
## 2018.11.16
更新 Windows 版及 Linux 版，變更項目如下：<br>
1. 「核心程式」更新至 2018.10.19 版本。<br>
2. 日文輸入法模式更換為韓文輸入法模式，在新模式下可以先打「.」，再打英文拼音，即可輸入日文平假名及片假名。<br>
3. mb 資料夾改為只存放「預設碼表」，其他檔案分類至以下資料夾：<br>
　 (1)ini 資料夾：存放各種輸入法模式之獨立組態設定檔。<br>
　 (2)Key 資料夾：存放各種輸入法模式之按鍵與組字字根對照表。<br>
　 (3)mbs 資料夾：存放「特殊碼表」系列之碼表（節省使用者須個別下載之時間及精力）。<br>
4. 新增「FileList.txt」，以便使用者瞭解各檔案之用途及其編碼種類。<br>
5. txt、ini 檔不再使用 UTF-8+BOM（帶 BOM）編碼，統一改為 UTF-8（不帶 BOM）編碼。<br>
　 如果使用 UTF-8 編碼可能會造成運作結果異常者，則使用 GB18030 編碼或 ANSI 編碼。<br>
　（ANSI 編碼在繁體中文環境下對應 Big5；在簡體中文環境下對應 GB2312）<br>
6. 修飾 Readme.htm、yong.ini 之內文。<br>
<br>
## 2018.12.08
更新 Windows 版及 Linux 版，變更項目如下：<br>
1. 刪除 mbs 資料夾（存放「特殊碼表」檔案之目錄），避免各版本檔案佔用磁碟空間（容量）過大。<br>
　 特殊碼表再區分為小小輸入法專用（&#42;.txt）及萊姆輸入法專用（&#42;.cin）（其他支援 cin 格式之平台亦可使用），<br>
　 採用獨立出來的方式，日後筆者較容易維護及重新發布，<br>
　 特殊碼表的下載網址是：[https://www.mediafire.com/file/bcaqpbyl1cd3ytr/Special.zip](https://www.mediafire.com/file/bcaqpbyl1cd3ytr/Special.zip){:target="_blank"}<br>
2. Linux 版新增「yong-tool32.sh」這一個檔案，<br>
　 改編自原本的「yong-tool.sh」，筆者以 32 位元版 Lubuntu 18.01 測試過，<br>
　 將原本會造成執行錯誤（及重新開機後會提示系統崩潰）的段落刪除，刪除後並不會影響小小輸入法的運作及功能。<br>
　 建議使用者在 32-bit Linux 環境下，改用此安裝檔。<br>
