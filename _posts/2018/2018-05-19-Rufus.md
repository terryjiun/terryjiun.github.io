Rufus 是一支可以將「可開機 ISO 檔」轉化為「可開機 USB 裝置」（例如：隨身碟、外接式硬碟）的程式，<br>
操作簡單、支援多國語言，而且還有免安裝版！<br>
目前最新的版本是 2.18，可以點選【[這裡](https://rufus.ie/zh_TW/){:target="_blank"}】直接下載免安裝版。<br>
<br>
假設您已經下載好 Bootable 的 ISO 檔和 Rufus，<br>
而且已經將空白（未儲存任何資料）的隨身碟插入 USB 埠，<br>
那麼就可以直接執行「rufus-2.18p.exe」，<br>
它會自動偵測使用者作業系統預設的語言，然後帶入對應的選單。<br>
如果在繁體中文 Windows 下執行，就會看到如下的視窗：

![Rufus](/assets/img/other/Rufus.png)

在這個視窗中，您只要確定「裝置」這一欄已經選擇正確的 USB 裝置的代號，<br>
接著，選取「使用映像檔建立開機片」右方的光碟片圖示，再帶入您已經準備好的 ISO 檔，<br>
然後「資料分割配置及系統類型」、「檔案系統」、「配置單元大小」，<br>
這三欄就會自動依照您選擇的 ISO 檔自動切換到對應的選項；<br>
您頂多就是在「磁碟區標籤」這一欄輸入您想要的名稱，<br>
最後，就可以按下「執行」按鈕，<br>
Rufus 就會開始將可開機 ISO 檔的內容複製到 USB 裝置，並且讓它成為可開機的磁碟。<br>
<br>
不用像筆者以往還要用「BOOTICE」這類的工具程式，<br>
先操作「分區管理」、「主引導記錄」…再來複製 ISO 檔裡的資料夾和檔案至 USB 裝置。<br>
Rufus 的操作過程就只有上述這些，非常簡單！<br>
