title: 新細明體更新套件（五）：補遺篇
date: 2008-11-12 10:10:00 +0800

---

在編寫前四篇文章時，<br>
突然在某一個「罕見字」列表的 PDF 檔案內看到這個字：<br>
「左邊三點『水』（氵），右邊『床』字去掉〝木〞（广）」：，<span style="color: red">㲿</span>（此字被收錄在 CJK Ext-A）<br>
（該 PDF 檔是我無意間搜尋到的參考資料）。<br>
在 Windows Vista 裡用「倉頡輸入法」（有設定支援全部字元集情況下）打不出這個字，<br>
於是我就用「[CNS11643中文標準交換碼全字庫](https://www.cns11643.gov.tw/){:target="_blank"}」（以下簡稱「全字庫」）搜尋了這個字，<br>
倉頡碼的確是我試過的「水戈」（我還試過「水卜竹」、「水戈一」、「水戈一竹」，也都拆不出這個字）。<br>
但是，用我打造的「泰瑞倉頡輸入法」是可以打得出這個字的，<br>
新細明體更新套件也確實包含「㲿」這個字。<br>
可以用來解釋的理由是：微軟雖然把字元集擴充了，但輸入法並沒有對應到 CJK 及其擴展 A、B 區全部的漢字<br>
（即使是最新的 Vista 內建的倉頡輸入法也一樣），<br>
以致於會讓人誤以為 CJK 及其擴充 A、B 區裡沒有這個字。<br>
（看來「泰瑞倉頡輸入法」的價值又提升了不少！）<br>
<br>
在運用全字庫網站找「㲿」這個字時，<br>
我有留意到它的「關於我們」裡有提到：<br>
「CNS11643 國家中文標準交換碼（簡稱國標碼）收編字數將達七萬餘字」<br>
但在其「問題集─9.是否可一次下載全字庫中所有字形？」<br>
卻明確的指出「全字庫共收集 81,260 個字形」。<br>
<br>
如果「81,260 個字形」是指目前收集 81,260 個字元的話，<br>
那它足足比 CJK 及其擴展 A、B 區的 70,195 個字元多出了 11,065 個字。<br>
只可惜的是這 11,065 個字的列表，目前我無法取得！<br>
本以為「㲿」這個字在全字庫多出的這 11,065 個字裡！<br>
後來才知道它是 CJK Ext-A 裡的字，<br>
也因為有這樣的因緣際會，因此才能寫出這篇「補遺篇」。<br>
<br>
基本上，如果你需要的字元，用上述四篇講述的方式仍然無法打得出來的話，<br>
先不必急著造字，去全字庫的網站找看看！<br>
比如找到我要的這個字後：<br>
[https://www.cns11643.gov.tw/wordView.jsp?ID=937519](https://www.cns11643.gov.tw/wordView.jsp?ID=937519){:target="_blank"}<br>
按下「適用 Windows XP 的造字處理工具」下方的<br>
「這裡可下載全字庫軟體包」，然後安裝「全字庫軟體包」。<br>
安裝後，再按下「適用 Windows XP 的造字處理工具」下方的<br>
「下載本字之全字庫楷宋字型與注音倉頡屬性資料包」，<br>
將「8EAECEAF.cnspkg」儲存至桌面後，<br>
直接點「8EAECEAF.cnspkg」兩下開啟，<br>
接著會看到轉入工具程式的畫面，<br>
請選擇一個空的「造字資料區」，<br>
最後按「加入」鈕加入這個字，<br>
然後程式會提示「造字轉入成功」，<br>
按下「OK」後，程式會自動關閉，<br>
手動重新開機後，就可以輸入這個字了！<br>
（只能使用倉頡及注音輸入，有的字並沒有對應的注音，<br>
所以用倉頡最保險！<br>
適用平台只有 Windows XP/Server 2003，<br>
Windows Vista/Server 2008 使用方式請參考第一篇回應，<br>
其餘作業系統忽略不談）<br>
<br>
另外，需要注意的是：<br>
1.全字庫網站的「問題集」中有述及：<br>
　「<span style="color: red">全字庫共收集 81,260 個字形，<br>
　目前所有 Windows 系統的自造字區並沒有辦法容納全字庫所有的字形，<br>
　頂多只能放約 5,809 個字而已，<br>
　無法將全字庫所有的字全部放進去。</span>」<br>
　所以儘可能用這 5,809 個「造字資料區」，<br>
　來放 CJK 及其擴充 A、B 區短缺的那 11,065 個字。<br>
2.因為每個人將字元儲存在「造字資料區」的位置是很難一致的<br>
　（大多數人的造字資料區是空的），<br>
　所以，假設你有用到本篇所述的方式來插入「罕見字」到文章裡，<br>
　要知道：用別台電腦看你這篇文章時，是看不到那個「罕見字」的！<br>
　（如果別台電腦的造字資料區不是空的，那很可能會顯示成另一個字）<br>
　所以建議直接從全字庫搜尋到的「罕見字」頁面裡，<br>
　將該字的圖片複製後，貼到文章或插入網頁裡。<br>
　您也可以從教育部《[異體字字典](https://dict.variants.moe.edu.tw/){:target="_blank"}》網站搜尋罕見字<br>
　（它提供的正字與異體字，共 106,230 字，比全字庫提供的字數還多！）<br>
　將該字的圖片複製後，貼到文章或插入網頁裡即可使用（只是它的異體字是用手寫的，較不美觀）。<br>
　但如果您的文章是不需要讓閱讀的人編輯的檔案，<br>
　您可以安裝 doPDF 這套軟體，<br>
  然後用列印的方式（列印時選擇 doPDF 的虛擬印表機）將檔案轉為 PDF 檔，<br>
　這樣即使閱讀的人的造字資料區是空的或與你的不同，<br>
　也不必擔心會顯示為空白或別的字，<br>
　因為 PDF 可以內嵌這些字的字型，使得檔案原貌不會隨不同電腦而有不同的面貌。<br>
<br>
補充說明：<br>
<br>
以上所說的「造字轉入」方式適用於 Windows Vista 和 Server 2008。<br>
但因為 Vista 和 Server 2008 的輸入法是不容許更改的，<br>
所以想要打出這些轉入的字的話，<br>
請參考這個部落格的「移植 Windows XP 內建中文輸入法至 Windows Vista/Server 2008」這篇文章<br>
移植 Windows XP 的倉頡輸入法到 Vista/Server 2008 上使用即可。<br>
建議先移植輸入法，再轉入想要的字<br>
（順序顛倒也可以，我在 VMware 上的 Vista 測試是 OK 的！）<br>
