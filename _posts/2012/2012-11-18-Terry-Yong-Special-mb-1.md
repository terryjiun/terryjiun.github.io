拜 Google 搜尋之賜，<br>
最近有不少人造訪「★小小輸入法已經支援 Windows 8 Metro APP 了！」這一篇文章，<br>
沒想到才半個月的時間，該篇文章瀏覽人次已經有六百多人，<br>
比起「★泰瑞版小小輸入法─Linux 版本篇」那篇文章發表一年多，<br>
瀏覽人次卻只有兩百多人來得強！<br>
這或許也顯示 Windows 8 Modern UI Style 的應用程式已經逐漸打開市場。<br>
<br>
經由痞客邦管理後台的「拜訪紀錄」分析，<br>
使我得知原來有一些注音輸入法的使用者，<br>
想要改用倚天41鍵、倚天26鍵、許氏鍵盤來打字。<br>
雖然有善心人士取得了這些鍵盤排列的注音輸入法對照表（碼表），<br>
並重新客製化後套用在「小小輸入法」平台，進而協助他們解決了問題。<br>
但是，事實上只要依據「[維基百科─注音輸入法](https://zh.wikipedia.org/wiki/%E6%B3%A8%E9%9F%B3%E8%BC%B8%E5%85%A5%E6%B3%95){:target="_blank"}」一文的介紹，<br>
將注音符號與各種鍵盤排列的對應關係，<br>
整理成「★Excel 檔案」（如有錯誤請來信告知），<br>
然後選用 Windows 8 內建的「微軟新注音」，<br>
（到「控制台」→「語言」或「新增語言」項下，<br>
點選「選項」→「新增輸入法」→「微軟新注音」），<br>
然後調整「微軟新注音」選項內的「鍵盤」對應成為「自訂」（如下圖），<br>
![微軟新注音設定](/assets/img/windows_ime/Microsoft-Bopomofo-Keyboard-Layout-1.png)<br>
再拖曳注音符號到想要對應的鍵盤上，最後再按「完成」即可（如下圖中的ㄅㄆㄇㄈ）。<br>
![自訂鍵盤](/assets/img/windows_ime/Microsoft-Bopomofo-Keyboard-Layout-2.png)<br>
微軟也貼心的提供了「匯出」和「匯入」功能，方便使用者將自訂的「鍵盤對應組合」移轉到別台電腦。<br>
如此便可以輕鬆將微軟新注音預設採用的標準鍵盤，改為倚天41鍵、倚天26鍵或許氏鍵盤。<br>
<br>
不過，為了滿足不同族群的需要，<br>
筆者還是另外從原本的「泰瑞注音」對照表轉出下列4個碼表供大家下載：<br>
一、[大千式鍵盤（標準鍵盤）排列的注音輸入法對照表](https://www.mediafire.com/download/nhtdid2bmj1gcak/Phon_STD.zip){:target="_blank"}。<br>
二、[倚天41鍵鍵盤排列的注音輸入法對照表](https://www.mediafire.com/download/n32tv6lqx2vozxd/Phon_ETen41.zip){:target="_blank"}。<br>
三、[倚天26鍵鍵盤排列的注音輸入法對照表](https://www.mediafire.com/download/udfp41ja5hfhvdl/Phon_ETen26.zip){:target="_blank"}。<br>
四、[許氏鍵盤排列的注音輸入法對照表](https://www.mediafire.com/download/rmlina668f5c99a/Phon_Hsu.zip){:target="_blank"}。<br>
由於原本的「泰瑞注音」已經依照常用字、破音字順序排列，<br>
所以這4個碼表或許可以滿足一些注音輸入法使用者的需求。<br>
<br>
這4個碼表在「泰瑞版小小輸入法」環境下的使用方式說明如下：<br>
1.下載您所需的注音輸入法對照表（例如：許氏鍵盤）。<br>
2.解壓縮後，將「Phon.txt」複製到「泰瑞版小小輸入法」根目錄下的「mb」資料夾裡，取代原有檔案。<br>
3.執行「泰瑞版小小輸入法」，切換到注音輸入法模式，即可正常使用。<br>
<br>
其實，小小輸入法本身並沒有優秀的智慧型選字功能，<br>
所以，筆者並不建議注音輸入法的使用者改用小小輸入法，<br>
微軟新注音輸入法、Yahoo! 奇摩輸入法、自然輸入法才是注音族應該選用的。<br>
遺憾的是 Microsoft 從 Windows Vista 以後，就不再提供「通用輸入法編輯工具」；<br>
而 Yahoo! 奇摩輸入法也從2011年第4季以後就未再更新版本，<br>
這些因素使得目前需要搭配智慧型選字的輸入法有發展上的限制。<br>
