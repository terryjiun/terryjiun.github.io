從原本使用 Windows XP 內建的（傳統）倉頡輸入法，到使用通用輸入法編輯工具產生「泰瑞倉頡輸入法」，再到使用自己客製化後的「泰瑞版小小輸入法-倉頡模式」（以下簡稱小小），這幾年來，我汰換輸入法軟體的目的無非就是想面面俱到且切合自己的需要。<br>
<br>
說實在的，一旦用慣某套輸入法軟體後，去用別人的電腦打字時，如果別人的電腦沒有安裝該套輸入法軟體，使用起來真的會很不習慣！還好小小有免安裝的優點，用別人的電腦打字時，只要下載並解壓縮小小，就可以順利打字了！打完再把小小刪掉，來去不留痕跡！因此這十個月來我對小小一直愛不釋手。<br>
<br>
Windows（本文說的都是正體中文版）XP 預設的系統字型只支援 CJK 字元集，所以它內建的倉頡輸入法只支援 CJK 字元集，這是缺點之一；缺點之二是某些 Big5 以外的字元，其組字字根有離譜的錯誤（如「学」）；缺點之三就是符號只能靠死背「ZXAL=…」這樣的對照組合來輸入，不然就是要用螢幕小鍵盤來輸入。<br>
<br>
Windows Vista/7 預設的系統字型支援 CJK、CJK Ext-A、CJK Ext-B 字元集，所以它們內建的倉頡輸入法可以經過調整後，支援這三區的字元。但是調整後，重碼字的情況會變得異常奇怪，比如：輸入「女戈人」時，應該會打出「以」字，但它卻會出現「<span style="color: red">幾、以、𠫙</span>」供使用者選擇，「幾」（組字字根應為「女戈竹戈」），竟變成第一個候選字，嚴重影響輸入速度及情緒，這是缺點之一；而前段所述缺點二、缺點三，使用 Windows Vista/7 內建的倉頡輸入法時仍會發生。<br>
<br>
如果使用經由通用輸入法編輯工具產生出來的「泰瑞倉頡輸入法」，雖然可以避免上述三個缺點，但是必須要經過繁複的安裝程序才可以使用，這是缺點之一；而且它對 64 位元版的 Windows Vista/7 支援程度不佳，這是缺點之二。<br>
<br>
小小輸入法較弱的地方是對螢幕小鍵盤（軟鍵盤）的支援程度不佳，另外，除非是使用內置版（安裝版），否則可能會有游標跟隨的問題。但螢幕小鍵盤只是方便輸入符號，它其實可以用自訂組字字根的方式解決；小小的安裝（內置）程序非常簡單，跟隨游標方面不致於有太大問題。而且即使是用免安裝（外掛）版，只要不是特殊的應用程式或遊戲軟體，跟隨游標方面完全沒有問題。 小小雖然只能用小寫英文打字，但不致於造成太大問題，介意此點的人，可以在碼表裡加入大寫字母的對照組合，只是如果是大、小寫混著打時，仍會出現問題。<br>
<br>
任何一種倉頡輸入法軟體，全面支援 CJK、CJK Ext-A、CJK Ext-B 字元集後，通常會造成打字時，受到重碼字的影響而變慢。雖然重碼字可以依照使用次數，將常用的調整到第一個，連續輸入時，可以不用選字，讓第一個候選字自動上屏，但是如果輸入以重碼字結尾的句子，如「早安」時，因為「安」和「㐄」是重碼字，後面沒有接著要輸入的字時，通常就必須要再按「1」選「安」。不過，這點在使用小小時，卻可以經過巧妙的安排，讓第二及其之後的重碼字必須刻意不按空白鍵出字，而是打完組字字根後，直接按對應的數字；組字字根打完後，如果按空白鍵，一律出第一個重碼字，反正，倉頡第二、第三…重碼字裡的常用字並不多，必須刻意不按空白鍵，而直接按對應數字的例子（如：佑、么…），大多可以背誦起來，藉此除可方便在同一模式下成功打出罕見字外，又可降低重碼字帶來的困擾。<br>
<br>
歸結來說，雖然各種倉頡輸入法軟體都有各自的缺點，但小小至少是瑕不掩瑜的！<br>
