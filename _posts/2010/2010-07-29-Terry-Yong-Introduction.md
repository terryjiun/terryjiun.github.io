這個月我密集的和一位網友以電子郵件討論輸入法對照表（碼表）的事情，<br>
經由他的介紹，我認識了「小小輸入法」。<br>
由於今年五月時，<br>
有網友來信詢問移植 Windows XP 內建輸入法至 64 位元版 Windows 7 上的問題，<br>
雖然最後我找到可以用 64 位元版 Windows Server 2003 的相關檔案來解決的方式，<br>
但那個方式並不完美，<br>
因為在 Win64 應用程式下，CJK Ext-B 的字元並不會正確的顯示在候選字窗格裡。<br>
可惜的是 Yahoo! 奇摩輸入法雖然有 64 位元版，但一樣不支援 CJK Ext-B 的字元，<br>
所以我一直在找有沒有其他的解決方案。<br>
本來我想將這件事擱下不管了！<br>
因為現階段我還不會用到 64 位元版的 Windows，就等 Yahoo! 奇摩輸入法改版再看看吧！<br>
但是，自從使用了「小小輸入法」後，我發現一切的難題都迎刃而解了！<br>
<br>
小小輸入法不但可以免安裝，而且還支援 Win32、Win64 的應用程式，<br>
更重要的是免費、有程式開發人員不斷的推陳出新、有很多意想不到的小功能…<br>
如果只使用自己會用到的輸入法對照表，再把用不到的程式、Skin 檔刪掉的話，<br>
它的容量可以精簡到 2MB 以下！<br>
（如果對照表只涵蓋 Big5 字元的話，甚至可以精簡到 1MB 以下）<br>
而且不需要安裝其他的輔助軟體！<br>
（比如：香草輸入法就需要安裝 .Net Framework，有些軟體則會要求安裝 Java…）<br>
常駐在記憶體中時，約佔 10 MB 的空間，這個數值並不算太大。<br>
<br>
小小輸入法不但支援 CJK Ext-B 的字元，而且還能改變候選字的字型，<br>
另外還有很多的參數可以供使用者自行調整，<br>
像是快捷鍵、聯想詞（相關字詞）功能、候選字字頻動態調整、漢字過濾…等；<br>
附屬功能則有字數統計、打繁出簡、軟鍵盤（螢幕小鍵盤）、萬用碼，<br>
另外，還有反查組字字根、線上字典、直通車、邊打字邊提示組字字根…等。<br>
<br>
字數統計只是暫存的數據，退出（結束）小小輸入法後就會清除，<br>
下次開啟（執行）小小輸入法時會再重新計算。<br>
直通車則是以組字字根結合程式指令的方式來出字，<br>
比如：可以設定使用者打了「.time」後，就會出現當下的時間，<br>
而且還有數種格式供您選擇。<br>
<br>
反查組字字根方面，如果您想查注音、拼音、倉頡碼、大易碼、行列碼…<br>
那麼，只要 mb 資料夾裡有注音、拼音、倉頡、大易、行列…的對照表，<br>
就可以先將輸入模式切換到想查詢的模式（如：注音）下，<br>
然後複製想查的字元（如：「會」）後，再按「Ctrl+?」（其實是「Ctrl+/」），<br>
接著，在畫面上就會看到「反查：會」的注音。<br>
它的反查功能比 Windows XP 內建的中文輸入法優秀，<br>
因為 Windows XP 只會列出一組反查到的組字字根，<br>
而小小輸入法會列出所有反查到的組字字根（如：「會」的所有唸法），<br>
可惜它是列出按鍵名稱（英數碼），<br>
使用者必須於腦海中再進行轉換（如：轉換為注音符號）。<br>
<br>
小小輸入法也可以過濾為只出現 Big5 的漢字，<br>
只要準備好一個 normal.txt，在文件裡編好 Big5 字元，<br>
然後再修改 yong.ini 的參數，將過濾字元的功能開啟即可。<br>
（這個功能可媲美 Windows XP 內建輸入法的「只顯示 Big5 字元」，<br>
詳情請上小小輸入法網站查看）<br>
<br>
Windows XP 通用輸入法編輯程式有這幾個限制：<br>
1.某一個組字字根對應的候選字不能超過 256 個；<br>
2.對照表宣告的可用按鍵越多，最大碼長就要越短；<br>
3.以「/」開頭的組字字根，必須再加一次「/」才能正常出字。<br>
以上這些問題都不會在小小輸入法裡發生，<br>
它徹底解決了完整版的泰瑞注音、泰瑞拼音原先只能依附在香草輸入法上的問題。<br>

執行小小輸入法後會在開始工作列通知區域（系統匣）出現黃色小蝸牛圖案，<br>
在它上面按右鍵可以選擇一些進階的設定；<br>
而「泰瑞倉頡」那一列的圖案則是一些基本的設定，<br>
輸入法名稱（可點選切換，此處為「泰瑞倉頡」）旁邊的圖案從左到右依序的功能是：<br>
中／英符號切換、中／英打切換、半／全型切換、軟鍵盤、繁／簡體切換、修改系統組態檔。<br>
