# 小小輸入法特殊功能介紹

小小輸入法與 Windows 內建輸入法相較之下，有下列特殊功能：<br>
<br>
## 一、便捷的日期與時間輸入方式
　　只要在碼表裡定義：<br>
　　<span style="color: blue">.date $mon月$day日 $mon月$day日（星期$WEEK） 農曆$RIQI<br>
　　.ymd $yyyy年$mon月$day日 $yyyy年$mon月$day日（星期$WEEK<br>
　　.time $hour:$min $hour時$min分 $HOUR點$MIN分</span><br>
　　就可以很容易的輸入想要的日期、時間格式。<br>
　　不過可惜的是：小小輸入法的作者是大陸網友，<br>
　　如果請他設計 $yyy 可產出民國年，那就太強人所難，而且可能會害到他。<br>
<br>
## 二、輸出詞組時自動斷行
　　以往想要輸入「name+空白鍵」（5個按鍵）就能自動打出：<br>
　　「<br>
　　泰瑞科技股份有限公司<br>
　　洪泰瑞<br>
　　聯絡電話：(02)8765-4321分機888<br>
　　」<br>
　　這是不可行的！<br>
　　但是使用小小輸入法時，只要在碼表裡定義：<br>
　　<span style="color: blue">name 泰瑞科技股份有限公司$/洪泰瑞$/聯絡電話：(02)8765-4321分機888</span><br>
　　（也就是用「$/」來代表斷行）<br>
　　就能達到以上所想要的輸入方式了！（<span style="color: red">以上為範例資料，並無該公司、該人名、該電話</span>）<br>
<br>
## 三、語音校對（同步發音）
　◎使用前提：<br>
　　控制台→語音辨識→文字轉換語音：可選擇且已選擇「zh-TW, HanHan」或「zh-CN, HuiHui」。<br>
　　Windows 7 使用者請參考【讓 Windows 7 專業版「文字轉換語音」可以選擇「zh-TW HanHan」語音】進行設置；<br>
　　Windows 8/8.1/10 正體中文版使用者，應該可以選擇「zh-TW, HanHan」一項。<br>
　◎「泰瑞版小小輸入法」的語音校對功能開啟方式如下：<br>
　　1.開啟輸入法主視窗。<br>
　　2.按下「Ctrl+Alt+Shift+S」熱鍵，將出現「開啟語音輸出」提示；再按一次會出現「停止語音輸出」提示。<br>
　　3.在該次 yong.exe 執行的階段，不管開啟／關閉輸入法主視窗多少次，會記憶最後一次開啟／停止語音校對的狀態。<br>
　　4.注意：在市集應用程式（Metro APPs 或稱 Modern APPs）裡無法使用上述熱鍵「開啟／關閉」語音輸入，<br>
　　　請先開啟傳統應用程式（如記事本），切換至「開啟」語音輸入後，再進入市集應用程式，打字時就會聽到同步發音。<br>
　　　而先開啟傳統應用程式，切換至「停止」語音輸入後，再進入市集應用程式，打字時就不會聽到同步發音。<br>
<br>
## 四、金額大寫格式（臨時英文模式）
　　打字時，如果要將「12345元整」輸出成「壹萬貳仟參佰肆拾伍元整」，<br>
　　可以按下臨時英文模式的熱鍵─左側 Ctrl 鍵，然後再敲鍵盤右側九宮格數字鍵的「12345」，<br>
　　就會出現「一二三四五」、「壹貳參肆伍」、「壹萬貳仟參佰肆拾伍元整」、「0x3039」四種格式供使用者選擇，<br>
　　使用上、下鍵移至想要輸出的格式種類（讓該格式變為粉紅色），再按下空白鍵讓該組字串「上屏」即可。<br>
　　對於需要經常製作買賣合約的人而言，這個功能特別實用！<br>
　　臨時英文模式也可以作四則運算，比如當您按下「123&#42;456」，再按下空白鍵，就會輸出「56088」這個計算結果。<br>
