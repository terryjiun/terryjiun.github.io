---
title: 細數 Windows 10 的各項缺點
date: 2015-11-12 10:10:00 +0800
categories: [作業系統]
tags: [Windows]
---

與 Windows 8/8.1 相比，有下列缺點：<br>
01. 在檔案名稱上，按右鍵，選「內容」，勾選「解除封鎖」，再按「套用」後，並不能真正刪除 NTFS Data Streams。<br>
　　（解決方式請參考【Windows 10 解除封鎖檔案與 AlternateStreamView 程式的應用】一文）<br>
02. 「工作列」上的圖示經常會有 Refresh 的現象。<br>
　　（估計與檔案總管有關，當光碟進片、退片時，工作列會自動重新整理而造成快閃現象，<br>
　　　OneDrive、Google Drive 進行同步時也可能會造成此種現象）<br>
03. 「電源選項」裡的「關機設定」已經勾選「開啟快速啟動」，但其啟動速度明顯不如 Windows 8/8.1。<br>
　　（2015.11.12 新推出的 Version 1511 有較明顯的改善）<br>
04. 執行 Windows Update 時，無法一眼就看出需下載的 hotfix 合計有多少 MB。<br>
05. 執行 Windows Update 時，無法篩選不要的 hotfix 或 Driver。<br>
　　（必須安裝 LTSB 版本才可篩選）<br>
06. Windows Defender 無法設定所有使用者對「歷程記錄」可以〝直接〞「檢視詳細資料」。<br>
07. 更新後的「天氣」（內建的 Modern APP）無法釘選多個城市的天氣成為「動態磚」。<br>
08. 將「視窗大小」手動拉至最大時，與螢幕邊界無法密合，會有空隙。<br>
　　（原本 Windows 8/8.1 的視窗外框線條較粗，Windows 10 的視窗外框線條較細，<br>
　　　因微軟改變界面後，系統未優化，以致於造成此種問題）<br>
09. 「控制台→聲音」的播放裝置預設為「耳機」，會導致使用者誤以為喇叭插孔插錯或驅動程式有問題。<br>
　　（其實只要將播放預設裝置改為「喇叭」即可解決）<br>
10.動態磚更新訊息的反應時間明顯落後 Windows 8.1（不只新聞，天氣更是讓人等到無言）。<br>
<br>
創新功能，但因為設計不完善而導致的缺點：<br>
01. 將「開始功能表」的「最常使用」捷徑，設為「不要在此清單中顯示」後，就不會再顯示了，而且無法重設。<br>
02. 「開始→所有應用程式」的排列方式，不能像 Windows 8/8.1 那樣隨自己喜好更改為依安裝日期、依類型、依名稱。<br>
03. Edge 的創新頻率不如 Firefox。<br>
　　（自 2015.07.29 微軟正式發布 Windows 10 的這三個月來，<br>
　　　Firefox 已經增加 Pocket、在分頁名稱上可點選「靜音」等功能）<br>
04. Edge 仍算是個陽春的產品，很多設定有待加入。<br>
　　（例如：結束時自動清除暫存檔、網頁字型可自行設定…）<br>
05. Cortana 推出台灣版可能還要再等個幾年！<br>
06. 部分程式的圖示在開始選單會變成空圖案，需重新開機才會恢復正常（筆者在 Version 1511 版遇過）。<br>
