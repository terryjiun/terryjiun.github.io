Windows 8.1 預覽版已經在2013年6月發布了！<br>
任何人都可以從 Microsoft 的官方網站下載到光碟映像檔，<br>
下載網址是：https://windows.microsoft.com/zh-tw/windows-8/preview-iso<br>
微軟提供的產品金鑰是：NTTX3-RV7VB-T7X7F-WQYYY-9Y92F<br>
<br>
為了測試小小輸入法在 Windows 8.1 傳統桌面及 Metro UI 環境下的相容性，<br>
我在 VMware 裡安裝了 Windows 8.1 Preview 32 位元繁體中文版，<br>
測試結果為：只要依照「泰瑞版小小輸入法─安裝設置篇」的說明安裝，即可正常使用。<br>
<br>
在測試過程裡，我順便試用了一下 Windows 8.1 內建的倉頡輸入法（以下簡稱「新版」），<br>
發現它和 Windows 8 正式版內建的倉頡輸入法（以下簡稱「舊版」）有很大的不同。<br>
舊版可以在「選項」裡設定預設輸入中文或預設輸入英文，<br>
還可設定支援的字元集（CJK、CJK Ext-A、CJK Ext-B），以及是否提示相關字詞。<br>
但是，新版完全沒有「選項」可以點選，預設就是輸入中文，<br>
每當要輸入英文時，就得按 Shift 鍵切換，用起來有點不方便！<br>
（因為我常常會忘了按切換鍵）<br>
不過，新版仿效了 Android 系統的設計，邊輸入就邊顯示候選字，<br>
比如輸入「心」這個字根時，就會提示組字字根以「心」開頭的字，像是「心、世、快…」，<br>
似乎也有學習功能，日久就會依使用者選字的頻率，將候選字順序做變化。<br>
遺憾的是：Android 系統的倉頡，選了「快」，<br>
可以再選「樂、速、要、到、點…」等相關字詞，<br>
但是 Windows 8.1 新版倉頡卻不支援這個功能！<br>
<br>
Windows 8.1 內建的注音輸入法和倉頡輸入法具有同樣的功能，<br>
支援的漢字似乎只限於 CJK 字元集，<br>
如果使用者想輸入 CJK Ext-A、CJK Ext-B 的字元，<br>
微軟提供的方案是：使用手寫辨識。<br>
大易輸入法、行列輸入法一樣不受重視，<br>
微軟在 Windows 8.1 裡提供的大易與行列，與在 Windows 8 裡提供的似乎一模一樣，<br>
而且同樣不支援 Metro UI（或稱 Modern UI、Windows 8-style UI）的 APP。<br>
<br>
或許將來泰瑞版小小輸入法也能實現「不必等組字字根打完，就會逐步提示候選字」的功能，<br>
只不過有兩個問題要克服：<br>
第一，候選字須按照常用字被使用的頻率來排序；<br>
第二，自動學習功能。<br>
第一個問題的解決方式是改變碼表排列順序，按照常用字被使用的頻率來排列碼表；<br>
原版的小小輸入法透過一些參數的調校，似乎也可以解決第二個問題，<br>
只是目前「泰瑞版小小輸入法」把自動調整順序的功能關閉了，<br>
因為「泰瑞版小小輸入法」主要是設計給慣用倉頡的人使用，<br>
這些功能對慣用倉頡者無用武之地，而且邊組字邊提示，會讓畫面變得有點亂。<br>
<br>
周永先生也有為小小輸入法製作了 Android 的版本，<br>
只是缺乏完善的教學，我試過安裝原生版的並不難，<br>
但要客製化為泰瑞版的就不大容易了！<br>
等 Windows 8.1 正式上市後，或許我會去買台平板來玩玩，<br>
到時才會有大幅改變泰瑞版小小輸入法的規劃，<br>
目前仍以「在 Windows 傳統桌面下搭配實體鍵盤可以順利使用」為目標。<br>
