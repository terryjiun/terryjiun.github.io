#泰瑞的世界（舊文）@痞客邦

前陣子，我在整理倉頡、注音、嘸蝦米的輸入法對照表（碼表）時，<br>
就曾經想過要再整理大易、行列的對照表，<br>
讓這些源自台灣、歷史悠久的輸入法都能支援 Unicode 3.1 收錄的 70,195 個漢字。<br>
當時以 Google 搜尋過「大易 cin」、「行列 cin」，<br>
得到的大易對照表幾乎都只支援一萬多字，<br>
而行列對照表則以香草輸入法內建的較為完整，但是它只支援六萬多字而已。<br>
<br>
近日，決定再好好努力看看！<br>
沒想到取得完整的行列對照表出奇的容易，而且我擔心的缺字問題也不嚴重。<br>
在 Unicode 3.1 收錄的 70,195 個漢字裡，它只短缺「𠔆」這個字，<br>
而且那個字應該是被行列官方誤以為重複而刪除，<br>
70,195 個字的對照表，能夠只短缺一個字，足以證明行列官方是很用心的！<br>
有這麼用心的原創著作人，電腦使用者可以很放心的學習行列、使用行列，<br>
我相信在 CJK Ext-C 的字型普及之後，<br>
行列官方也會更新他們編製的對照表來支援 Unicode 5.2 新收錄的 4,149 個字。<br>
（倉頡、注音方面，CNS11643 團隊已經整理了很多 CJK Ext-C 的漢字，<br>
到時可以連上 CNS11643 的網站查詢它們的倉頡碼及注音）<br>
<br>
反觀大易方面，<br>
我上網搜索了半天，連個完整支援 Unicode 1.0 收錄的 20,902 個漢字的對照表都找不到，<br>
要找到支援 Unicode 3.1 收錄的 70,195 個漢字的對照表更是比登天還難。<br>
Windows 內建的大易輸入法有支援 Unicode 1.0 收錄的漢字，<br>
而且應該是完整的支援，只可惜無法將它轉換為正確、可用的 txt 檔。<br>
而 Mac OS 雖然也有內建大易輸入法，<br>
不過從 Apple Store 網站上販售的「大易輸入法字典」的預覽圖來看，<br>
Mac OS 的大易應該只支援 Big5 字元集（13,053 個漢字）。<br>
Linux 系統上使用的 gcin 也是相同的情況，<br>
不管是大易三碼或大易四碼，對照表裡的漢字都只有一萬多個，<br>
而且這兩份對照表還是由太易資訊公司（大易的原始著作人）提供的。<br>
<br>
我覺得大易官方沒有更新對照表以支援 Unicode 1.0 收錄的 20,902 個漢字並無大礙，<br>
因為嘸蝦米官方（行易公司）連個免費的、公開的對照表都不提供，<br>
（就算提供了也只支援 Unicode 1.0 收錄的 20,902 個漢字而已）<br>
結果蝦米族樂園的網友們還不是弄出了加字加詞檔，<br>
尤有甚者，熱心的蝦米研究室成員們更編製了 CJK、<br>
CJK Ext-A、CJK Ext-B 的對照表供大家免費使用。<br>
所以只要有人無私的付出，打字族群也能享用免費的、完整的大易對照表。<br>
大易輸入法的專利在民國94年9月21日已經消滅了，<br>
（連上「中華民國專利資訊檢索系統」搜尋大易發明人「王贊傑」的姓名就能找到專利資料）<br>
情況如同現今的嘸蝦米狀態，<br>
只是至今仍未見到有熱心的人士自行編製大易對照表。<br>
<br>
或許大易的使用者擔心一旦自行編製大易對照表後，會產生法律糾紛；<br>
又或許大易真的是沒落了！因為它沒有其他輸入法好用。<br>
它只是把拆字時所取的字形取大一點，以方便學習、快速上手，<br>
但說實在的，它用到的按鍵太多、重碼問題也不輕微，這些都是致命傷。<br>
沒落的輸入法，當然就會少了熱情投入、為她奉獻的人。<br>
<br>
行列官方很明確的請大家不要再用行列40鍵，轉而使用行列30鍵才是上策；<br>
但是大易官方卻沒有這樣做，而且還推出能自動選字的大易二碼。<br>
說實在的，要叫電腦使用者去學這種自動選字的大易二碼，<br>
那他們還不如學倉頡的字根原理後，直接用 Windows 內建的「新速成」。<br>
因為大易官方的態度不明確，<br>
所以在搜尋網頁時，大易三碼和大易四碼出現的機會是差不多的。<br>
實務上，大易三碼的重碼率比大易四碼嚴重，<br>
而且 Windows、Mac OS 內建的大易都是四碼，<br>
所以大易三碼應該會較少人用，<br>
但我卻很意外的找到大易三碼的 Patch 檔，<br>
這個 Patch 檔有補上一些非屬 Big5 字元集的罕見字，<br>
但還是沒有完整支援 Unicode 1.0 收錄的 20,902 個漢字。<br>
而且要將大易三碼轉換為大易四碼必須一一校對，費時又費工。<br>
如果一開始拿到的就是較為完整的大易四碼對照表，<br>
我還可以先用 Excel 的「=LEN()」函數先將 4 碼字的組字字根挑出，<br>
存成純文字檔後，再用另一個 Excel 工作表將文字檔匯入，<br>
匯入時強制分隔為一碼一欄，刪除第三欄後，<br>
合併起來，再貼回原來的 Excel 工作表裡去，就大功告成了！<br>
所以，大易三碼的對照表並沒有四碼的來得有實用性，<br>
要找就要找四碼的對照表才是我所需要的。<br>
<br>
倉頡發明人朱邦復先生在他的著作裡提過：<br>
「<br>
若一種輸入法與某個軟體結合，那就是一種陽謀，<br>
即使學會了，可能也只有少數幾種用途。<br>
更可畏的，是某種外來力量的支配，有人得利，就有人受害！<br>
」<br>
我覺得無蝦米就是這種情形，所以我不鼓勵網友們學無蝦米。<br>
因為行易公司連授權給 Microsoft、Apple，<br>
讓他們將無蝦米當作 Windows、Mac OS 內建的輸入法都不願意，<br>
他們只想將無蝦米與他們出的軟體緊密結合！<br>
得利的當然是行易，受害的其實是蝦米族，<br>
只是蝦米族很多人都用盜版，所以不覺得受害。<br>
太易公司雖然有授權給 Microsoft、Apple，<br>
讓他們將大易四碼當作 Windows、Mac OS 內建的輸入法，<br>
可是採取的策略仍是要求必須事先取得授權，<br>
說穿了，太易公司仍是想掌控大易與某個軟體結合的主導權。<br>
<br>
行列發明人廖明德先生很支持朱邦復先生的理念，<br>
所以在行列官方網站上有提到：<br>
「<br>
中文輸入法必須跟發明人的生命及推廣該輸入法的公司分離，<br>
當使用者學會之後，不管發明人是否在世，各系統都要能夠繼續支援，<br>
使用者才有永遠的保障，就像倉頡和注音輸入法一樣。<br>
要讓使用者可以永遠使用，只有像倉頡一樣開放授權才可能，因此行列採開放授權，<br>
任何一種系統，都可以找工程師把行列寫進系統，成為系統的一部份。<br>
行列輸入法公開免費授權給各中文系統作者及廠商，<br>
歡迎把行列輸入法加入任何中文系統，<br>
不需另外要授權書，也不需付任何權利金，<br>
只是請把訊息告知行列，好在本網站公告或提供下載。<br>
」<br>
<br>
免費、公開、支援大字庫的對照表是這種開放理念的落實，<br>
要是太易公司、行易公司能無私、不求利益的以推廣中文、造福打字族群為宗旨，<br>
推出這樣的對照表，並採取開放授權，那麼相信這個世界會更美好！<br>
