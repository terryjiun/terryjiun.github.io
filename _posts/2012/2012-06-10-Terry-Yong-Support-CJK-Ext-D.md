date: 2012-06-10 10:10:00 +0800
categories: [泰瑞版小小輸入法]
tags: [Terry_Yong, 倉頡, 碼表]
---

雖然，要讓泰瑞版小小輸入法內附的「泰瑞倉頡」支援 CJK Ext-C/D 字元集並不是一件困難的事，<br>
但是，在整理「泰瑞倉頡」的 CJK Ext-C/D 字元集碼表時，還是發生了一些小插曲！<br>
<br>
首先，我差一點就要重灌電腦了！<br>
因為更新 Windows 7 的新細明體（2套字型）的方式真的比較麻煩！<br>
在 Windows 7 裡，刪不掉、移不走新細明體，即使在 WinPE 環境下也是一樣。<br>
後來，我乾脆在 Ubuntu 裡刪除新細明體，<br>
並且把 Windows 8（消費者預覽版）的新細明體複製到 C:\Windows\Fonts，<br>
結果，重新進入 Windows 7 後，桌面上的中文字都變成了「□□」！<br>
開啟檔案總管後，看到的文字全部變成空白…（不是「□□」喔！而且連英文字也顯示不出來！）<br>
只好再進到 Ubuntu 裡刪除新細明體（這次不敢直接用複製的方式置換了），<br>
重新進入 Windows 7 後，情況有比較好一點，英文字可以正常顯示了！<br>
趕快進入檔案總管，找到 Windows 8 的新細明體（mingliu.ttc、mingliub.ttc）後，<br>
在檔名上按右鍵，選「□□(I)」（「安裝」二字已經變成了「□□」），<br>
之後，就像是在瞎子摸象，安裝後的訊息顯示什麼，我完全不知道！<br>
所幸，再次重開機後，更新成功！<br>
這下子 Windows 的新細明體顯示漢字字數從 70,195 個字變成 74,566 個字了！<br>
再來就可以擴充「泰瑞倉頡」的輸入法碼表了！<br>
<br>
其次，我赫然發現我在 2010 年向行政院主計處申請的全字庫光碟，<br>
裡面居然沒有 CJK Ext-C/D 字元集的倉頡屬性，真是無言以對！<br>
所幸，「倉頡之友．馬來西亞」網站有提供我所需要的碼表，<br>
檢查了一下，並無任何字疏漏，<br>
於是將「泰瑞版小小輸入法」內附的「泰瑞倉頡」擴充為支援 CJK Ext-C/D 字元集。<br>
<br>
如果各位網友想要使用 CJK Ext-C/D 字元集裡的漢字，<br>
前提是必須先安裝「7.01」版本（Windows 8 內附）的「新細明體」及「新細明體-ExtB」，<br>
安裝方式請自行參考「Windows 8 內建的新細明體已經支援 CJK Ext-C/D 字元集了！」一文。<br>
如果不須使用 CJK Ext-C/D 字元集裡的漢字（或不想升級新細明體），<br>
則請自行將碼表裡的「擴展C區、擴展D區」段落刪除，<br>
以免候選字窗格出現「□」。<br>
<br>
前幾天，我到辦公室後就把輸入法及字型更新了一下，<br>
從此，我的電腦能直接打出、顯示出 74,566 個漢字了！<br>
不過，最後我還是踢到鐵板了！<br>
因為有同事請我幫忙製作參賽者的名單時，<br>
其中有一個人的名字有個字是上「𥫗」（竹）下「昀」，<br>
結果我居然打不出來！<br>
起初，我不相信有人會用這 74,566 個字以外的漢字當名字，<br>
結果，同事拿這位參賽者的身分證影本給我看，我才相信她沒有寫錯字！<br>
後來，我去[全字庫網站](https://www.cns11643.gov.tw/){:target="_blank"}查詢了一下，<br>
才知道原來這個字還沒有被 Unicode 收錄，難怪打不出這個字來！<br>
<br>
目前，在「泰瑞版小小輸入法」的各種輸入法模式裡，<br>
只有「泰瑞倉頡」可以打出 CJK Ext-C/D 字元集的漢字，<br>
這已經比 Windows 8 內建的倉頡輸入法厲害了！<br>
因為 Windows 8 內建的倉頡輸入法只支援到 CJK、CJK Ext-A/B 字元集的漢字。<br>
行列輸入法的官方網站上，雖然有提供 CJK Ext-C/D 的碼表，<br>
但是經過我檢查後，發現有缺少了 48 個漢字，<br>
前幾天，我已經寫信到官網的聯絡信箱，<br>
並且和行列輸入法官網的人員取得聯繫，等到他們提供完整的碼表，<br>
屆時，使用「泰瑞版小小輸入法」的行列輸入法模式也能打出 CJK Ext-C/D 字元集的漢字了！<br>
至於注音、拼音、大易、嘸蝦米，就無福享受了！<br>
