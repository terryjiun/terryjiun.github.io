特別聲明：<br>
下文著於 Windows 8 尚未發布之前，<br>
Windows 8/8.1/10 內建的「新細明體」（含「新細明體-ExtB」）已支援 CJK Ext-C、CJK Ext-D，<br>
想要升級 Windows XP/Vista/7 內建的「新細明體」的使用者，<br>
請參考《[Windows 8 內建的新細明體已經支援 CJK Ext-C/D 字元集了！](https://terryjiun.github.io/posts/Windows-8-mingliu/){:target="_blank"}》一文。<br>
以下為 2010 年（Windows 8 尚未發布前）的原作。
<hr>
支援中日韓統一表意文字（CJK）的字型有很多，<br>
繁體中文 Windows 內建的標楷體、新細明體、微軟正黑體都有支援，<br>
商業字型（如：華康字型、文鼎字型、金梅字型）也多半支援這個字元集。<br>
<br>
支援中日韓統一表意文字擴展A區（CJK Ext-A）的字型比較少，<br>
較常見的有：<br>
1.「新細明體更新套件」中的「新細明體」（同時支援 CJK 及 CJK Ext-A 字元集）。<br>
2.繁體中文 Windows Vista、Windows 7 內建的新細明體、微軟正黑體，<br>
　還有微軟雅黑體（Microsoft YaHei）、仿宋體（FangSong）、楷體（KaiTi）。<br>
3.越南人開發的「hannomH」（HAN NOM A）字型。<br>
4.中華民國行政院主計處開發的「全字庫正楷體」、「全字庫正宋體」。<br>
<br>
支援中日韓統一表意文字擴展B區（CJK Ext-B）的字型也比較少，<br>
較常見的有：<br>
1.「新細明體更新套件」中的「新細明體Ext-B」。<br>
2.繁體中文 Windows Vista、Windows 7 內建的新細明體Ext-B。<br>
3.越南人開發的「hannomH」（HAN NOM B）字型。<br>
<br>
支援中日韓統一表意文字擴展C區（CJK Ext-C）的字型更難找，<br>
目前我找到的是日本人開發的「hanazono」（HanaMin）字型。<br>
它的介紹網頁網圵是：[https://glyphwiki.org/hanazono/](https://glyphwiki.org/hanazono/){:target="_blank"}<br>
下載網址則是：[https://glyphwiki.org/hanazono/hanazono-20170904.zip](https://glyphwiki.org/hanazono/hanazono-20170904.zip){:target="_blank"}<br>
另外，大陸人開發的「超大字符集通用字體支持包」也有支援。<br>
<br>
